Bulk Import — From a Website or Google Sheet

Paste either a book-listing page URL (any online bookshop) or a link to a public Google Sheet — Books House detects which one it is automatically, reads it, and shows an editable review table before anything is added to your catalog.

Website: fetched through a public CORS proxy (browsers block direct cross-site requests) — some sites may still block it, in which case add those books manually.

Google Sheet: share it as "Anyone with the link can view," then paste the normal edit/share URL. First row should be a header row — a Title column is required; Price, Category, Source, URL, Cover Image, and PDF columns are optional (order and exact wording don't matter).

Cover images / PDF links / Website links in your sheet are hyperlinked text (e.g. a cell that just says "Cover" or "PDF")? A plain sheet export can't see those links — paste a free Google Sheets API key below and Books House will read the real link behind each cell instead. Get a key here (enable "Google Sheets API", then create an API key under Credentials — no billing needed for public sheets). Leave blank to fall back to plain text export (hyperlinked cells will come through empty).
